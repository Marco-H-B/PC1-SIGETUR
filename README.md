## 📌 Resumen del Caso 12

**PERÚ TOURS** requiere una plataforma web para automatizar su flujo comercial:

1. **Afiliación:** Turistas no socios se afilian digitalmente al programa de socios.
2. **Solicitud de Viaje:** El socio solicita paquetes a medida (destino, n° personas, fechas/horas de partida y regreso).
3. **Cotización y Diálogo:** El agente receptivo formula cotizaciones; el socio las evalúa, aprueba o registra observaciones de ajuste.
4. **Pago y Formalización:** El socio abona cotizaciones formalmente aprobadas mediante pasarela segura.
5. **Auditoría Gerencial:** Agente y Gerente consultan cotizaciones canceladas u observadas por rangos de fecha.
